# Original project (unchanged)

Files of the first version of the project, kept exactly as received (byte-identical to the original archive
`ICALTER2026_proyecto_completo.zip`) so that every change can be traced.

| Folder | Content |
|---|---|
| `original_scripts/` | The nine Python scripts of the first analysis (`01_inspect.py` to `08_mode_month.py`). They read the microdata from absolute paths of the author's computer and are not used by the current pipeline. |
| `original_tables/` | The seven result tables they produced. `results/tables/comparison_original_vs_revised.csv` compares them with the revised results. |
| `original_figures/` | The five original figures. |
| `original_manuscript/` | The first manuscript in English and Spanish, with their PDFs. |
| `README_original.md` | The original README. |

The reasons for each change are in `../CHANGELOG.md` and in the audit reports of the delivery
(`07_AUDITORIA_CIENTIFICA/AUDITORIA_INICIAL.md`).
